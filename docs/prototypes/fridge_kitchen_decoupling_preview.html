備料為臨時準備狀態，透過 LocalStorage 跨頁持久化，不額外污染後端資料庫。

3. 常備底料 ➔ 在庫扣庫 vs 輔料免扣庫

在庫蛋/菜具備真實 UUID；未在庫的青蔥/白飯標註為常備輔料，僅作風味提示，避免核銷報錯。

4. 料理結算 ➔ 唯一 completionKey

進入 CookingMode 手肘按鈕導引，結算時本人親自確認外食差額，符合 CONTEXT.md 防重複入帳。

5. 食安救援 ➔ SafetyModal 檢核

執行分裝冷凍時，強制勾選無酸腐發霉，呼叫 POST /inventory/:id/rescue 延長 14 天。

6. 冰箱容積 ➔ boxSize 動態計算公式

動態加總 S=1L, M=2.5L, L=5L，即時計算 130L 佔比與進度條，無需後端修改。
